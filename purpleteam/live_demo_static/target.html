AI purple teaming

Red-team your AI agents.
Blue-team the fix. Prove it.

purpleteam plugs into a multi-agent AI system, maps its agents and tools on its own, attacks them the way a real adversary would, fixes what breaks with reviewed patches only, and re-attacks to prove every fix holds. Each step is signed into a tamper-evident audit trail.

How a run works

  1. 01
    Discover Reads the system's own code to map its agents, their tools and what each tool can do.
  2. 02
    Attack Red team: attack datasets and adaptive attacks. A breach counts only when an agent actually does the harmful thing.
  3. 03
    Patch Blue team: fixes chosen from a reviewed catalog, with source edits applied only after independent verification.
  4. 04
    Verify Re-attacks the patched system with the same payloads. A fix counts only if every attack now holds.
  5. 05
    Sign Every attack, fix and verdict is signed into an append-only, tamper-evident ledger.
