When you start

  1. 01Discover Reads the target's own code to find its agents, their tools and what each tool can do. The map builds live in the Discovery tab.
  2. 02Attack Sends the attack dataset at the agents as they are, and proves every breach by what an agent actually did, never by reading its words.
  3. 03Patch Picks fixes from a reviewed catalog: runtime guards, plus exact source edits that are verified before they apply.
  4. 04Verify and sign Re-attacks the patched agents with the same payloads, then signs the verdict into a tamper-evident ledger.
Start the assessment → Runs the custom dataset. Choose another mode in the console.
